# Case Martech - Implementação de Tracking

## Objetivo

Este projeto foi desenvolvido como um case técnico de Martech, com o objetivo de implementar uma estrutura de mensuração digital para acompanhar interações dos usuários em uma página web.

A implementação contempla a configuração de eventos e parâmetros para análise de comportamento e validação do tracking em ambiente publicado.

## Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* Google Analytics 4 (GA4)
* GitHub Pages

## Implementações realizadas

* Estruturação de eventos de mensuração;
* Captura de interações do usuário;
* Configuração de parâmetros enviados ao GA4;
* Validação do disparo dos eventos em ambiente publicado.

## Validação

Os eventos foram validados após a publicação do projeto por meio da análise das requisições realizadas no navegador, garantindo que as informações esperadas fossem enviadas corretamente para o GA4.
